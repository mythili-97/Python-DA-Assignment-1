# Python-DA-Assignment-1
This assignment focuses on performig Data Analysis using Numpy arrays for numerical computations and Pandas Series,DataFrame for data manipulation and analysis.
#Project Overview:
This project focuses on performing Data Analysis using NumPy and Pandas.It demonstrates fundamental techniques for numerical computation,data manipulation,filtering,indexing,slicing and aggregation using temperature and transaction datasets.

#Objectives:
*Work with NumPy arrays for numerical computations.
*Use Pandas series for one-dimensional data analysis.
*Use Pandas DataFrames for structured data manipulation.
*Perform filtering,Boolean operations and aggregate functions for data analysis.
*Design structured analysis on temperature and transaction data.

#Tools and Technologies:
*Python|NumPy|Pandas|Google Colab/Jupyter Notebook.

The project uses:
1.Temperature dataset:
*Creating Numpy arrays and checking array properties such as data type,size and shape.
*Finding maximum,minimum and average temperature.
*Performs array slicing.

2.Temperature dataset:
It is used to practice:
*Creating Dataframe,Accessing rows using loc and iloc.
*Selecting specific columns based on given conditions.
*Removing rows and columns.
*Performing basic data analysis.

#Key Pandas Concepts Practiced
Pandas Series:
Creating a Series,Custom indexing,Integer-based indexing,loc,iloc,Slicing,Boolean filtering,Removing entries.

Pandas DataFrame:
Creating a DataFrame from a dictionary,Filtering data,Adding new columns,Dropping rows,Dropping columns,Basic aggregation and analysis.

NumPy Concepts Practiced:
*Creating NumPy arrays using np.array(),Checking array properties,
*Using .size and .shape
*Celsius to Fahrenheit conversion
*Finding maximum and minimum values
*Calculating the mean
*Array indexing and slicing
*Performing numerical calculations

Conclusion:
This project provides hands-on experience with the fundamental concepts required for data analysis using Python. It strengthens understanding of NumPy arrays, Pandas Series, and Pandas DataFrames and demonstrates how these tools can be used to work with numerical and structured datasets.
